# Async-RBench
agent benchmark
As the execution paradigm of long‑range Agents gradually shifts from sequential tool calls to concurrent SubAgent delegation, the core capabilities of the main Agent are no longer confined to static planning or selecting the next tool. Instead, it needs to dynamically maintain, revise and reconstruct plans amid parallel progress of multiple tasks, continuously changing execution statuses and asynchronous feedback of results. Asynchronous execution introduces complex interrupt‑driven control flows: some SubAgents may return early and trigger adjustments to the current plan; critical results may arrive late and overturn existing assumptions; conclusions from different SubAgents may conflict with one another; certain returned results may become invalid due to changes in the environment or plan states. Accordingly, the main Agent must determine when to proceed with execution, wait for critical dependencies, cancel or restart tasks, as well as how to identify the timeliness of results, resolve information conflicts, and integrate asynchronous feedback into global decision‑making. Existing Agent Benchmarks mostly adopt synchronous, sequential or one‑shot result‑aggregation execution modes and rarely explicitly construct interrupt events triggered by asynchronous returns from SubAgents. Hence, they cannot systematically diagnose Agents’ dynamic replanning capabilities in real‑world concurrent environments. To address this issue, we propose an Agent Benchmark targeting SubAgent asynchronous‑interrupt scenarios. By controllably setting events including early result returns, delayed critical results, conflicting conclusions, stale information, task failures and changes in plan dependencies, this benchmark examines whether the main Agent can continuously maintain task states and dependency relationships, and promptly complete plan revision, task rescheduling, waiting‑or‑cancellation decision‑making and multi‑source result integration after interrupts occur.
