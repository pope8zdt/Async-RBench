# Scheduler Selective Replan (structure-derived)

The executable participant instruction is [task/task.yaml](task/task.yaml). This case is derived from the Terminal-Bench task `llm-inference-batching-scheduler` (lock commit `d28711d0da2675d0bb1d56de45ae5df6082438a3`): the public cost model and baseline packer are byte-identical upstream files, and the request buckets are deterministic engineered fixtures generated from the upstream cost model. Two bucket optimizers and a shared global shape allocator run concurrently; the combined plan is final only after both bucket validators have returned. Private scoring checks that the passing bucket's plan survives verbatim, the failing bucket is replanned within the shared eight-shape budget, and the combined plan is reverified before completion. The upstream task suite is not replayed.
