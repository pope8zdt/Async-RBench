What to prepare提交材料

Place evidence.zip and submission.json in your private repository. Open a new private issue with /submit <commit SHA>. A revision needs a new submission.将 evidence.zip 和 submission.json 放入私有仓库，新建私有 Issue，填写 /submit <提交 SHA>。修改版本需重新提交。
