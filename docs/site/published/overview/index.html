Async-RBench

评测代理收到新结果后，能否正确调整正在进行的工作。Evaluate how agents revise ongoing work when new results arrive.

子任务并行执行，结果先后返回。我们检查主代理是否修改受影响的部分、保留有效成果、重新验证，并最终完成任务。Subtasks run concurrently and return results at different times. We check whether the main agent revises affected work, retains valid progress, verifies the update, and completes the task.

任务成功率 STask success S
最终任务是否全部完成。每次运行判定成功或失败，再汇总为百分比。Whether the full task was completed. Each run succeeds or fails; rates are reported as a percentage.
